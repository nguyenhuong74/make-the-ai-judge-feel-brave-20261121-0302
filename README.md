# Make the AI judge feel brave

Entry for the make.fun competition
`make-the-ai-judge-feel-brave-20261121-0302`.

## What it does

`main.py` (Python 3.13, standard library only) writes one short,
original relaxing text to `/output/entry.txt`. The text is fixed and
deterministic: every run produces the same bytes.

## Run

```sh
python3 main.py
```

## The text

> Evening light turns the colour of apricots. A sparrow lands on the
> rail, folds its wings, and stays. The kettle has gone quiet. Steam
> thins above the cup. Nothing here needs hurrying. Sit a while. The
> chair holds your weight, and tomorrow can wait its turn at the door.

269 characters (Unicode code points), valid UTF-8, within the 1–280
limit.
